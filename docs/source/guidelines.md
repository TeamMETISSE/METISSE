# Community guidelines

 ## Contribute to METISSE
 
 We are always working on improving the functionality of METISSE. 
 If you would like to contribute by adding a new feature or creating with a bug fix, please [fork](https://github.com/TeamMETISSE/METISSE/fork) the METISSE repository from GitHub. Once you are ready, create a [pull request](https://github.com/TeamMETISSE/METISSE/pulls) with your proposed changes.

 ## Seek support or report problems with METISSE
 
If you need help with METISSE or want to report any problems, you can create an [issue](https://github.com/TeamMETISSE/METISSE/issues/new) on Github. For any other request, use [discussions](https://github.com/TeamMETISSE/METISSE/discussions).
